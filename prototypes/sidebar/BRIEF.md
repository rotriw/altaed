# 原生资源侧栏增量

用户目标：左侧作为 IDE 资源起点，参考 VS Code 的分工，为将来云存储扩展。
继承 PRODUCT.md、DESIGN.md 的白色紧凑应用风格。只扩展左边栏，不改变已验收的欢迎页、编辑区操作条和右侧测试栏。

结构：44px 活动栏，220px 资源栏；32px 标题，28px 分组，28px 文件行。打开文件与保留草稿可折叠；新建/打开在标题右侧。选中行淡蓝，hover 只改变前景，键盘焦点有细线。云图标只预留位置，标注尚未接入。底部设置打开现有全局设置。

本网页仅验证布局，示例文件不读写磁盘、不运行代码。原生使用真实会话文档和草稿。900px 窗口仍保留编辑器最小宽度，资源栏可拖动和收起。扩展边界是具名侧栏贡献描述，不引入云同步或插件市场。
