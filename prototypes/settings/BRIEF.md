# 设置窗口

Mode: Operate。沿用 DESIGN.md 与已认可测试区的配色、系统字体、浅底标题条、细线和无阴影控件。

任务：软件设置管理全局编辑器与工作台偏好；文档运行配置是另一独立窗口，管理编译、运行与输出比较。两者没有范围切换。未来插件通过带命名空间的描述注册分类、选项、选项值、验证和条件显示，无需改动表单布局。用户 2026-11-02 明确要求此职责分离，覆盖此前的新文档默认值／当前文档切换提案。

布局：960×700 内容窗口，192px 分类栏；34px一体标题栏（Windows 32px）、52px 底部操作；32px 正文边距。页面由共享 schema 的 layout 定义。应用窗口使用相同逻辑像素；系统标题栏不属于网页内容复刻范围。

第一屏：左侧搜索与编辑器／工作台分类，右侧字体、字号、行号和换行。每项按“调整项目 → 解释 → 选项”排列，使用 13px 半粗标题、12px／20px 解释和下方控件，组间留 28px。软件设置另有“快捷键”，与原生共用 commands.json。文档运行配置的首屏为编译器、参数、工作目录。没有卡片、装饰图标、工具栏或宣传区域。应用显式提交草稿，取消撤销未应用内容；切换分类保留草稿。搜索展示匹配字段及来源分类；错误就地显示，不丢失内容。

插件扩展示例只在网页的原型控制条显式开启，清楚标注示例，不代表已实现远程提交。正式软件在没有插件注册时不显示虚构插件选项。

验证：键盘、搜索空态、输入错误、浮点条件项、取消／应用、插件选项和窄窗口；最终原生与网页同内容尺寸比较。遵循原有视觉系统，无 DESIGN.md 替换。

颜色主题：用户否定了420px宽、文本居中的旧控件。改为280×30px左对齐选择器，右端箭头，列表显示由主题语法色生成的四色色样和选中图标。说明一行。下方420px宽、四行C++配色预览与网页／原生共用数据，选择只改变草稿预览，应用才改变软件主题。

主窗口和设置窗口统一原生外框。设置顶部只保留“设置”与范围提示，不重复系统标题和56px大页头。Windows仅在右侧显示caption控件；网页是布局预览，实际系统行为在发布前单独验收。
