# 测试区比较器排版

Mode: Operate。沿用已验收的 altaed 原生测试区颜色、字体、196px 用例与细分隔线；本轮只重排比较器入口，并把过时的网页执行按钮放回编辑区底部。不是品牌改版，不生成网站式卡片或宣传内容。

用户反馈：底部状态栏式比较菜单位置难看，需要参考 CP Editor，先网页再迁移。2026-11-03 用户已验收，授权迁移 GPUI；明确不需要响应式切换，原生保留固定结构和面板拖拽。

空间关系：运行信息 → 测试标题（计数、添加）→ 比较器行（标签、可伸缩下拉框、导入、参数设置）→ 可滚动用例。比较规则属于当前文档的整个测试集，紧挨测试标题；不占用底部状态栏，也不挤入每个用例。低频容差、外部比较器超时与参数就地展开。左右文档切换验证各自配置隔离。

CP Editor 官方 TestCases.cpp 的 titleLayout / checkerLayout / scrollArea 证明了这一分层：
https://github.com/cpeditor/cpeditor/blob/master/src/Widgets/TestCases.cpp

固定尺寸：测试标题36px；比较器行40px（26px控件、上下7px）；面板默认520px；12px内边距；导入与设置共用14px线性SVG图标。比较规则、用例状态与字段标签最低11px。细线明确分区，无 hover 灰块、阴影或装饰动画。

桌面验证：面板520/340px；下拉/参数展开、浮点错误、长文件名、空状态、500例、两文档切换、Enter换行、WA打开左右联动Diff。网页原型中的历史窄视口检查不构成原生需求，原生不实现移动布局或宽度断点。所有运行结果为明确标注的演示，浏览器只选择比较器文件，不读取或执行它。

用户追加：每例不再显示“比较预期输出”复选框。预期输出长度为零时只观察输出，有内容自动比较；输入框用“留空仅观察输出”提示。默认内置截图中的八种比较规则，并保留已有的自定义浮点容差能力。默认规则同时忽略文末换行，覆盖此前保留末尾换行的临时决定。
