# 测试区分隔原型

模式 Operate；继承 altaed 原生浅色主题与顶层菜单原则，只验证右侧测试工作区。依据用户反馈及 CP Editor 官方 home-center-2.jpg，运行信息在上、测试数据在下，用细分隔线和可拖动边界区分。每例三个同级数据区域：输入、只读实际输出、预期输出。悬停仅使用前景色／细线变化，无灰色背景块或阴影。

本原型是结构扩展，不替换视觉品牌。主要任务为 Enter 换行、编辑数据、查阅输出、浏览大量用例、调整运行信息与测试区比例。500 例压力入口仅用于验证可见范围渲染，演示结果不代表执行源码。GPUI 复现应使用惰性用例控件、明确多行回车绑定，并避免逐帧复制全部文档与结果。
