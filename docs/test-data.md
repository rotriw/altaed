# 样例文件与输出差异

测试比较结果以绿色对钩 `Accepted`、红色叉号 `WrongAnswer` 展示。编译失败、超时、运行错误、未设置预期输出等状态分别保留，不混入答案比较结果。修改代码、测试或配置后，原结果显示为旧版本。

## 文件绑定与编辑

输入和预期输出标题旁提供文件入口。在独立纯文本窗口中，可以打开 UTF-8 文件、编辑、另存为，并通过“保存并绑定”关联到当前样例；“转为文本样例”保留当前文字并解除文件关联。取消和直接关闭会确认未保存修改，普通应用退出入口也会先处理未完成的样例文件编辑。

绑定后的主测试框显示文件预览，点击文件名可重新打开编辑。文件修改由弹窗明确保存；绑定信息仍随代码文档的元数据/恢复草稿保存。旧弹窗回写前校验原文档、样例内容和编辑视图身份，避免删除/重建样例后误改其他用例。写文件前核对原内容与修改时间，发现外部编辑则拒绝覆盖；保存采用原子替换。没有跨进程文件锁或跨文件事务。

文件在源码目录内时保存相对路径；另存为代码时调整相对引用，保持指向原文件。未保存代码的绑定使用所选绝对路径。独立文档的绑定信息与内联备份互相隔离；显式绑定同一物理文件的多份代码，会在下次运行共同读取该文件的新内容。

## 运行快照与性能

执行前在后台读取本次选中的输入与预期输出，固定为该次运行的数据。文件输入内容作为标准输入，预期文件内容交给所选 checker；题目自身的 `freopen`/文件 I/O 约定仍需单独适配。原始导入样例保持不变。

一次运行的数据总量默认上限64 MiB，可在“文档运行配置 → 运行 → 测试数据总上限”修改。主测试框最多预览16 KiB；内置弹窗编辑上限4 MiB，更大的文件只读预览并可直接绑定，运行使用完整内容。文件读取和保存不在 UI 回调中执行；测试列表继续按可见范围创建控件，弹窗的修改标识使用廉价版本计数，不逐帧复制全文。

当前没有文件系统实时监视器。外部工具改动文件后，再次运行会重读文件；已有结果仍属于上次运行快照。在应用弹窗保存文件后，绑定预览刷新，已有文件样例结果作废。

## 当前文档的比较方式

预期输出为空时仅运行并观察，有内容则自动比较；每例不显示比较复选框。输入框使用“留空仅观察输出”提示。绑定预期文件时，以运行前读取的实际内容判断；空文件也只观察，无法读取的绑定文件仍报告错误，不能当成未设置。

比较配置按代码文档归属，同题的其他解法互不影响。用户已验收网页排版并授权迁移：原生在测试标题下面以“比较器选择 / 导入 / 参数”成行，移除底部入口。参数就地展开；无效值不进入执行配置，也不能悄悄沿用旧值运行测试。文档切换保留各自的表单，外部窗口改变比较设置后重建对应控件。原生保持固定桌面排版、保留面板拖拽，不采用响应式断点。

默认八种内置规则：

| 规则 | 行为 |
| --- | --- |
| 忽略行末空格和文末换行 | 去除每行末尾的 ASCII 空格/Tab/CR 以及文末空行；保留行中空格和中间空行，兼容 LF/CRLF |
| 严格一致 | 逐字节相等，空格和换行均参与比较 |
| ncmp | 按有符号64位整数序列比较，拒绝溢出和非整数 |
| rcmp4 / rcmp6 / rcmp9 | 有限浮点数序列，最大绝对/相对误差分别1e-4 / 1e-6 / 1e-9；相对区间以预期值为基准 |
| wcmp | 比较空白分隔的字符串序列，区分大小写 |
| nyesno | 只接受 YES/NO 序列，大小写不敏感 |

内置数值规则无需外部程序。新增命名和常用数值比较规则参考 [testlib 官方 checker](https://github.com/MikeMirzayanov/testlib/tree/master/checkers)，并保留既有“自定义浮点容差”配置。旧数据已经选定的 Tokens / Exact / Float 设置继续读取；新建文档默认采用忽略行末空格和文末换行。

“导入比较器”仅接受当前平台的现成原生可执行文件，不编译源码或执行脚本。导入时校验文件而不运行；下次测试才使用它。调用接口为：

```
checker INPUT ACTUAL EXPECTED [附加参数…]
```

前三个参数均为本次运行固定文件的绝对路径；附加参数在文档运行配置中每行填写一个，不经过 shell。返回码沿用 [testlib 标准定义](https://github.com/MikeMirzayanov/testlib/blob/master/testlib.h)：0 为 Accepted，1/2/4/8 为 WrongAnswer；其他返回码（包括部分分数）、崩溃、启动失败、超时和输出超限显示“比较器错误”。详情保留比较器的诊断、返回码和耗时；取消显示“已取消”。没有预期输出的用例只运行代码，不调用比较器。

比较器自行决定空白和数值容差，IDE 不预处理它的文件。每次运行先复制比较器到独立目录（最多256 MiB），后续修改原文件不影响这次运行；数据、源码和配置同样固定。比较器默认每例超时2秒，可在比较设置中调整；输出共用当前文档的输出上限。Windows 子进程隐藏控制台并将原比较器目录和所选编译器目录加入子进程 DLL 搜索路径。其他相邻资源和动态库不自动打包，需使用可独立运行的比较器。

## Diff

`WrongAnswer` 文字和每例的 `Diff` 按钮都可打开差异窗口。有预期输出的旧版本结果也可查看，窗口会标明快照状态。使用固定的预期/实际值，不在打开 diff 时重新读取源文件。

两列按行对齐，显示各自行号、插入/删除的空行占位和行内差异区间。垂直滚动使用同一列表，水平滚动使用同一偏移；触控板横向滚动或 Shift+滚轮时两侧一起移动。提供前后差异跳转，空格、Tab、CR/LF 和文件末尾换行可见，空白标识可以关闭。checker 的忽略空白、浮点容差规则保持独立，因此 `Accepted` 也可能有原始文本差异。

计算在后台完成。大输出从首个差异附近截取两侧各不超过128 KiB，最多渲染6000行，窗口明确提示截断；实际输出与预期输出快照分别保存在本次执行目录的 `case-N/stdout` 和 `case-N/expected`。

文档/会话格式写入版本5，读取版本1至5；旧二进制拒绝新格式，避免静默丢失文件绑定或改变比较规则。Companion 本地收据格式写入版本4，读取版本1至4。Companion 网络协议没有因此改变，也不会把网页提供的文件名当成本地绑定路径。
